## Content Strategy

### Best Title
**"Land Clients Without More Discovery Calls (I Built the System Live)"**

Why it wins (agent's reasoning): a coach/consultant outcome, not a tool name — understandable in 3 seconds. Implies a real build without requiring the viewer to know what Claude Code is.

On "Claude Code" in the title: leave it out. Searchability is owned by developer content, which repels the coach/consultant viewer. Mention Claude Code once verbally inside the video.

### Backup Titles
1. "Stop Selling Your Time on Discovery Calls — Build This Instead"
2. "The Offer That Gets Coaches Booked Without Cold Outreach"
3. "If You Want High-Ticket Clients, Build This System First"
4. "I Built a Client-Booking System So You Can Copy It"
5. "Full Offer-Building System in Under 15 Minutes (No Strategist Needed)"

### Thumbnail Text
1. "No More Cold Calls"
2. "Built Live, 14 Min"

### Hook
"If you're a coach or consultant living off discovery calls and referrals, here's the problem: you don't have a business, you have a job that never turns off. In the next 14 minutes, I'm going to take one vague coaching idea and turn it into a specific, priced offer you could sell today — no more chasing calls, no more guessing what to charge. And I'm going to build the whole system live, on screen, so you can copy it."

### Retention Map (sums to 14:00)
- **0:00–0:20** — Hook.
- **0:20–1:30** — Thesis: "The money is not in the tools. It's in the system." Reject the AI-agency genre. Set expectation: real build, timer running.
- **1:30–2:15** — Demo idea + the four teammates by job title.
- **2:15–5:30** — SCOUT segment (longest): market wants, fears, misunderstandings, live.
- **5:30–8:30** — STRATEGIST segment: offer sentence reveal + price, then before/after compare.
- **8:30–8:50** — Honesty beat.
- **8:50–10:30** — PUBLISHER (compressed): content angles tied to the sale.
- **10:30–11:50** — CLOSER (compressed): lead magnet + follow-up sequence.
- **11:50–12:40** — Value ladder with price ranges.
- **12:40–13:30** — Recap: timer, thesis, works for any rough idea.
- **13:30–14:00** — CTA transition slot.
