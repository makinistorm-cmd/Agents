## Conversion System

### Lead Magnet

**Name:** The Revenue Agent Template

**Promise:** Run the exact relay you just watched — Scout, Strategist, Publisher, Closer — on your own business idea, and get a first-draft market read plus a priced offer sentence in about 20 minutes.

**Contents:**
1. **The 4 Teammate Files** — Scout.md, Strategist.md, Publisher.md, Closer.md. Same role prompts used on screen, generalized to any business idea. Labeled by job title only — no "agent," "subagent," or "system prompt" language.
2. **The Business Brief Starter** — fill-in-the-blank version of the brief (audience, core promise, constraint, voice). Under 5 minutes.
3. **The Runbook (Run Your Own Relay in 20 Minutes)** — copy-paste-level handoff instructions in two versions:
   - *Claude Code version* — for anyone who has it installed.
   - *Copy-paste version* — same four prompts in a normal Claude.ai or ChatGPT chat window, zero install. This is the default path.
4. **The Handoff Checklist** — one page showing what good Scout and Strategist output look like, so a non-technical user can tell if the relay is working.

**First-20-minutes quick win:** Fill in the brief → run Scout → hand Scout's output to Strategist. Result: a market-reality check and a first-draft priced offer sentence for their own business.

**Why now:** The loudest question when the video ends is "will this work on mine?" This answers it in 20 minutes with the same teammates.

### Follow-Up Sequence

**Email 1 — Day 0** · Subject: *Your Revenue Relay is attached — here's your first 20 minutes*
Deliver the download; "Don't read it. Run it." Brief → Scout → Strategist. Two versions inside (Claude Code / copy-paste). CTA: run Scout first, reply with what it found.

**Email 2 — Day 1** · Subject: *The tool isn't the system*
Belief shift: a system can be re-run on every new idea; tools feel like progress, systems produce something sellable. CTA: run the relay on one real idea today.

**Email 3 — Day 3** · Subject: *"I'm not technical" and "it'll sound generic" — answered*
Teammates are job titles, not software. Generic output comes from skipping research: "Skip Scout, get generic. Run Scout, get specific." Uses the video's coach example. CTA: go back and run Scout before Strategist.

**Email 4 — Day 5** · Subject: *Watch me build your offer live (90 minutes, not 9 days)*
Invite to the Offer Architecture Sprint: live working session on your business, leave with positioning, priced offer, first content angles. CTA: save your seat.

**Email 5 — Day 7** · Subject: *Some businesses need more than a Sprint*
Qualified path to the Revenue Systems Build for businesses with real traffic/list/sales process. Done-with-you; keep the system. CTA: reply "Build."

### Sales Path
1. Video → template (wants to know "will this work on my idea").
2. Template → engaged prospect (runs Scout + Strategist; replies to Email 1 — tag repliers).
3. Day 1 → reactivation for non-runners before any offer.
4. Day 3 → workshop candidate ("came out vague" / "got stuck on handoff" replies).
5. Day 5 → workshop buyer ($197–$497).
6. Sprint attendee → premium signal (asks for the full build, has list/traffic).
7. Day 7 → discovery conversation (replies "Build").

Gate each step on behavior (opened, ran, replied, attended), not just time.

### Friction Check
1. Claude Code install is a real barrier → lead with the copy-paste version.
2. Manual handoff is ambiguous → show the literal copy/paste step.
3. Leftover dev jargon in files → audit filenames and headers.
4. Timer mismatch → never claim "14-minute system"; build time is ~9.5 minutes.
5. No income claims creeping into edits.
6. $197–$497 spread reads as undecided → pin one price or tier it.
7. Big jump from $0 to $3K+ → keep the "existing business" qualifier on the Build.
8. "I read these" is an ops commitment → have a reply process before launch.
9. Asset name must match everywhere: "Revenue Agent Template."
